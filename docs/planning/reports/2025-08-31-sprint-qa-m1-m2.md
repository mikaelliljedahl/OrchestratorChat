## Action Items (PR-ready)

### A) Finish M1 (OAuth) securely and idiomatically
1) Implement DI service boundary
   - Add IAnthropicOAuthService, IOAuthStateStore; register in DI.
   - Move logic from ProvidersController into the service; keep controllers as thin wrappers.
2) Enforce PKCE/state server-side
   - /start: generate and store state + code_verifier in IOAuthStateStore keyed by user/session; return authorize URL only.
   - /callback: validate state; use stored code_verifier to exchange code; save tokens; clear used state.
   - Remove or strictly validate /exchange using same server-stored verifier/state (no client-generated verifier allowed).
3) Update components
   - Inject IAnthropicOAuthService; call StartAsync to get authorize URL; open via JS; poll GetStatusAsync.
   - Avoid intra-app HttpClient; remove JS eval usage (add small JS helper if needed).
4) ProviderFactory typing/logging
   - Replace object CreateClient with typed methods or interfaces; inject ILogger/ILoggerFactory via DI.
5) Tests
   - Unit: StartAsync stores verifier/state; HandleCallbackAsync validates state; ProviderVerificationService AnthropicOAuth status.
   - Integration: end-to-end start?callback?status with mocked HTTP; no token leakage.

### B) Make M2 skeleton usable end-to-end
1) Session scoping
   - Orchestrator.razor: create/select a Session; pass sessionId to saves.
2) Persist Team/Plan
   - OnTeamSaved ? TeamPlanService.SaveTeamAsync(sessionId, team); re-load to confirm.
   - OnPlanSaved ? TeamPlanService.SavePlanAsync(sessionId, plan); re-load; set CommittedAt when “Commit Plan” clicked.
3) Bind to real agents
   - TeamSetup: load agents from AgentService; add members with real AgentId/Type/Name and role; drop fake Guid id.
   - PlanEditor: populate owners from persisted Team members; save PlanStep.Owner with real AgentId.
4) Visual confirmation
   - Add a simple “Committed Plan” panel/timeline summary after save.
5) Tests
   - Unit: TeamPlanService SaveTeam/SavePlan round-trip.
   - Component/integration: Orchestrator saves and renders persisted team/plan.

### C) Unblock Chat
1) Subscribe to groups
   - ChatInterface: on agent select/init ? AgentHub.SubscribeToAgent(agentId); on dispose ? UnsubscribeFromAgent.
   - Optionally OrchestratorHub.JoinSession(sessionId) to receive session-scoped replies.
2) Default agent selection
   - After LoadAgents(), if none selected ? use GetDefaultAgentAsync() or _agents.FirstOrDefault(); enable input.
3) Sidebar affordances
   - Make list items visibly clickable; selection state enables input.
4) Tests
   - Component: selecting an agent triggers SubscribeToAgent call.
   - Integration: subscribed client receives ReceiveAgentResponse.
